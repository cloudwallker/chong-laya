# 人工案例集

`cases.jsonl` 包含 30 条完全虚构的中文购物情境，用于“今天你冲了吗”的本地小规模评测。每行是一个 JSON 对象：`id` 是唯一编号，`context` 是输入文本，`expected` 是英文选项键（`buy`、`wait`、`skip`），`category` 概括主要判断因素，`pair_id` 连接同一情境的两种说法，`variant` 标明 `original` 或 `paraphrase`。

标注顺序如下：

1. 预算压力优先：购买会挤占房租、生活费或其他必要支出时，标为 `skip`（不冲），即使用途明确也一样。
2. 用途明确、预算足够、现有物品无法满足需求，三个条件都明确时，标为 `buy`（冲）。
3. 现有替代品足够使用，而购买冲动主要来自折扣或倒计时促销时，标为 `skip`。
4. 预算、实际需要或可用替代品尚不清楚，以及购买时机或适配情况未确定等信息不足时，标为 `wait`（等等）。缺少预算信息本身不等于有预算压力。

每个选项有 5 个语义不同的情境，每个情境各写 `original` 与 `paraphrase` 两条意思等价的自然中文表述。因此这里是 **15 个语义对、30 条文本**，不是 30 个独立样本；同一 `pair_id` 的预期标签一致。`category` 用于解释主要因素，不表示这些因素互斥。

这些预期标签是依据上述规则人工编写的基准，用来观察模型输出与改写一致性。案例集不是训练集，基准标签也不构成客观的消费正确率或个人财务建议。此处不预设任何模型评测成绩。
